# Team Members & Responsibilities / สมาชิกทีมและหน้าที่รับผิดชอบ

# 1. Phoom
## Role / ตำแหน่ง:
**Project Leader / Project Manager / DevOps Lead**  
**หัวหน้าโครงงาน / ผู้จัดการโครงการ / ผู้นำด้าน DevOps**

### Responsibilities / หน้าที่:
- Project planning and management / วางแผนและบริหารโครงการ
- Sprint/task management / จัดการงานและระยะเวลา
- Team coordination / ประสานงานภายในทีม
- Technical decision making / ตัดสินใจเชิงเทคนิค
- Backend architecture oversight / ดูแลภาพรวมโครงสร้าง Backend
- DevOps infrastructure / ดูแลระบบ DevOps
- Docker / Kubernetes
- CI/CD pipeline
- Deployment management / จัดการ deployment
- Security overview / ดูแลด้านความปลอดภัย
- System scalability planning / วางแผนรองรับการขยายระบบ

---

# 2. Mai
## Role / ตำแหน่ง:
**Frontend Leader / UX/UI Lead**  
**หัวหน้าฝั่ง Frontend / ผู้นำด้าน UX/UI**

### Responsibilities / หน้าที่:
- Mobile application development / พัฒนาแอปพลิเคชันมือถือ
- Web frontend development / พัฒนาเว็บ frontend
- UI/UX design / ออกแบบประสบการณ์ผู้ใช้
- Design system management / ดูแล design system
- Responsive design / รองรับหลายอุปกรณ์
- User flow optimization / ปรับปรุง user flow
- Frontend architecture / วางโครงสร้าง frontend
- Component structure / จัดการ component
- User experience consistency / รักษามาตรฐาน UX

---

# 3. Chan
## Role / ตำแหน่ง:
**Full Stack Support Engineer / Integration Engineer**  
**วิศวกร Full Stack สนับสนุน / วิศวกรเชื่อมต่อระบบ**

### Responsibilities / หน้าที่:
- Frontend support / สนับสนุน frontend
- Backend support / สนับสนุน backend
- API integration / เชื่อมต่อ API
- Authentication implementation / ระบบยืนยันตัวตน
- Feature development support / สนับสนุนการพัฒนาฟีเจอร์
- Cross-system integration / เชื่อมต่อระบบ
- Bug fixing / แก้ไขปัญหา
- Technical backup / สนับสนุนทุกฝ่าย
- Internal testing support / ช่วยทดสอบระบบ
- Shared module development / พัฒนาโมดูลร่วม

---

# 4. Oak
## Role / ตำแหน่ง:
**System Analyst / Documentation Lead / QA Lead**  
**นักวิเคราะห์ระบบ / ผู้นำด้านเอกสาร / ผู้นำด้าน QA**

### Responsibilities / หน้าที่:
- User requirement gathering / เก็บ requirement ผู้ใช้
- Survey and research analysis / วิเคราะห์แบบสอบถามและงานวิจัย
- System Requirement Specification (SRS)
- Use Case design / ออกแบบ Use Case
- UML diagrams
- Thesis documentation / เอกสารวิทยานิพนธ์
- Proposal documentation / เอกสาร proposal
- QA/QC process / กระบวนการประกันคุณภาพ
- Test case creation / สร้าง test case
- User Acceptance Testing (UAT)
- System validation / ตรวจสอบระบบ
- Research support / สนับสนุนงานวิจัย
